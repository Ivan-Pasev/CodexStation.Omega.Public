# CodexStation Ω Public

**Status:** Genesis / public constitutional and reproducibility surface  
**Private R&D authority:** CodexStation Ω NEXT canonical Google Drive working tree  
**Public-repo authority:** publication-filtered public canon only

CodexStation Ω Public is the public, provider-independent constitutional, semantic, verification and distribution surface for the CodexStation Ω architecture.

It is designed to make the strongest defensible parts of the architecture inspectable, forkable, testable and portable across model and host providers without allowing any provider, model, chat, notebook or repository to silently become the Station's identity or constitutional authority.

## Architectural thesis

CodexStation Ω is a provider-independent cybernetic architecture for persistent, evidence-governed, corrigible, tool-using cognitive systems. It separates:

- identity from model/provider;
- capability from authority;
- claims from evidence;
- formal proof from empirical confirmation;
- execution from validation;
- memory from hidden chat state;
- private R&D canon from public publication;
- platform compilation from semantic mutation.

The project explores architectures relevant to increasingly capable general-purpose AI systems while keeping claims evidence-bounded. “Digital 2.0” and “Civilization 2.0” are engineering horizons and research programs, not claims of achieved societal transformation.

## Publication boundary

This repository does **not** automatically mirror the private R&D working tree.

A candidate crosses the public boundary only through:

```text
SOURCE
-> LINEAGE
-> SECRET/PII CHECK
-> LICENSE/IP CHECK
-> CLAIM/EVIDENCE CLASSIFICATION
-> AUTHORITY CEILING
-> PROVENANCE
-> PUBLICATION WITNESS
-> COMMIT
```

A private source may inform a public carrier without being copied verbatim.
