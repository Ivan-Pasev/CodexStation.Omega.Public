## ProjectHarvestCapsule

One dense capsule SHOULD represent one project/epoch and carry:

- project identity and source roots;
- authority split and active lineage;
- source inventory and revision/hash pointers;
- typed object and relation maps;
- evidence/status boundaries;
- reusable kernels and skills;
- contradictions, negative results and open gates;
- candidate global deltas;
- next highest-value map target.

## Knowledge lattice

The lattice is a typed versioned graph, not a vector store.

Recommended object classes:

`Project Source Definition Claim Evidence Invariant Gate Receipt Skill Kernel Protocol Schema TheoryObject Model Dataset Experiment Observer Capability Authority Artifact Release NegativeResult Contradiction NoGo Hold Dependency Supersession Bridge ContextCapsule ProjectHarvestCapsule Holotope ArchetonicPlate`

## Holotope

A Holotope is a bounded coherent graph slice for one mission.

It is a context view, not a new authority source.
