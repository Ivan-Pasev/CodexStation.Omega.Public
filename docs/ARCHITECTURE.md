## Logical architecture

The public canon uses five logical carriers:

1. **OMEGA_CORE** — constitutional runtime and control law.
2. **OMEGA_CRYSTAL** — ontology, evidence, research, engineering and continuity semantics.
3. **OMEGA_SKILL_SPINDLE** — typed reusable methods.
4. **OMEGA_THEOREMATIC_SPINE** — formal objects and status-separated theorem program.
5. **OMEGA_PUBLIC_ANCHORS** — inspectable public bridges.

Physical sharding is permitted for provider limits only when the logical identity and semantic fingerprint remain explicit.

```text
LOGICAL_CARRIER == SAME_SEMANTICS
PHYSICAL_SHARDING != CANON_FORK
```

`ENTER`, `EXIT`, `EXPORT`, `FORK`, `RECOVER`, `MIGRATE`, and `REJOIN`.
