## Primary decision

The Foundry is **adapter-first**.

```text
NATIVE SOURCE SEMANTICS
    !=
SHARED INTEROP ABI
    !=
OMEGA AGGREGATE VIEW
```

A native source retains authority over its own definitions and execution semantics. A cross-system adapter may translate fields, dispositions or identities only when the mapping is explicit and its losses are declared.

## Compatibility classification

`DIRECT` means an inspected source exposes a closely corresponding construct.

`ADAPTER` means an explicit semantic adapter is required.

`PARTIAL` means only part of the shared ABI is covered.

`NONE_OBSERVED` means the inspected source set does not establish the capability.

These labels are architectural observations, not product maturity rankings.

## First executable reference slice

The first integrated runtime SHOULD minimize trusted code and compose existing tested parts through adapters:

```text
CanonicalState
-> CandidateTransition
-> SemanticVerdict
-> AuthorizationDecision
-> ExecutionSpec
-> isolated execution
-> ExecutionReceipt
-> WitnessReceipt
-> event append

```

The first slice SHOULD deliberately exclude autonomous authority escalation, hidden memory authority, unbounded recursive execution, and unreviewed external code.

## Project harvesting interface

A mounted project is deep-mapped into a ProjectHarvestCapsule. Reusable digital/system artifacts are routed into KernelRecord candidates. Theory/model artifacts remain namespaced and keep their own epistemic status.

A REALICA or other science project can therefore contribute:

- formal methods;
- equation/proof/checking kernels;
- simulation tooling;
- uncertainty/evidence methods;
- structured model/observer/experiment objects;

without its authorial physical hypotheses being promoted into established science.
