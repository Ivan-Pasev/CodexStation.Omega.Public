# Ω Project Deep Map / Harvest Skill

## Trigger

Use when the operator supplies a canonical project folder/repository URL or asks to harvest, map, metabolize, crystallize, aggregate, port, quantize or cross-link a project into CodexStation Ω.

## Required boot order

1. Read project START_HERE / CONTINUE_HERE.
2. Read STATE_AND_HANDOFF.
3. Read project AGENTS / constitutional instructions.
4. Resolve canonical root, active lineage, authority split, current frontier and releases.
5. Inspect only the minimum additional sources needed to form a coherent local map.
6. Read the Ω mass aggregation contract.
7. Compare with the global lattice only after local coherence is achieved.

## Hard boundaries

```text
SOURCE_PROJECT_CANON != OMEGA_AGGREGATE_VIEW
READ_ACCESS != WRITE_AUTHORITY
SAME_LABEL != SAME_LINEAGE
LATEST != AUTOMATIC_AUTHORITY
CLAIM != EVIDENCE
FORMAL_PROOF != EMPIRICAL_CONFIRMATION
IMPLEMENTATION_PASS != SCIENTIFIC_PASS
EXTERNAL_TECHNIQUE != CANONICAL_AUTHORITY
BLACK_HOLE != SOURCE_ERASURE
COMPRESSION != AUTHORITY_PROMOTION
```

## Deep-map pipeline

```text
SCAN
→ MAP
→ SOURCE_FINGERPRINT
→ CLASSIFY
→ SEGMENT
→ OBJECTIZE
→ DEDUP

→ HOLOTOPE_REFOLD
→ PLATE_COMPILE
→ KERNEL / SKILL ROUTE
→ CRYSTALLIZE
→ WITNESS
→ SYNC
```

## ProjectHarvestCapsule output

Emit or update:

- project identity and aliases;
- source roots / repositories;
- authority and lineage maps;
- current frontier / releases;
- source inventory with revisions/hashes when available;
- stable local objects;
- relations;
- evidence classes and status vector;
- kernel candidates;
- skill candidates;
- contradictions / no-go / negative results;
- open gates;
- quarantined items;
- candidate global deltas;
- next target;
- observed time;
- `authority_delta = NONE`.

## Kernel extraction

For every reusable computational / engineering kernel record:

- intent;
- input/output contract;
- state model;
- authority boundary;
- determinism;
- side effects;
- required capabilities;
- algorithm;
- data structures;
- interfaces;
- test harness;
- formal evidence;
- performance evidence;
- security assumptions;
- failure modes;
- portability;
- dependencies;
- license/IP;
- version/status.

Prefer extraction of P0/P1/P2 kernels before large theory prose where engineering value is high.

## Dedup outcomes

Only choose among:

```text
SAME_OBJECT
ALIAS
VERSION_SUCCESSOR
DERIVED_OBJECT
COMPETING_OBJECT
CONTRADICTORY_OBJECT
UNRELATED
UNKNOWN
```

Aggressive deduplication is allowed only for `SAME_OBJECT` or `ALIAS`.

## Local NEXT()

Inside a mounted project:

```text
LOCAL_DELTA = resolve changed frontier
MAP(LOCAL_DELTA)
HARVEST(high-value reusable material)
METABOLIZE()
EMIT(ProjectHarvestCapsule delta)
SYNC(Ω lattice)
RECOMPUTE(local + global frontier)
```

Do not abandon the source project's work goal.

## Public-safety / release rule

Private or unpublished source content may be represented by metadata, stable IDs, abstracted public-safe structure and provenance pointers, but may not be copied into a public repository without explicit publication admission.
